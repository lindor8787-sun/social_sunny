# Social ERP · 個人社會資訊站

版本 1.0 ｜ 建立日期 2026-11-18

一個自動更新的個人資訊站：時事、產業與媒體動態、行銷與方法論、菜價行情、法律知識、金融知識與試算工具，集中在一頁。

**完全免費、不需要任何 API 金鑰、不用綁信用卡、沒有用量限制。**
所有資料都來自公開 RSS 與政府開放 API，由 GitHub Actions 定時抓取。

---

## 一、怎麼架起來（約 10 分鐘）

這個專案不需要申請任何服務、不需要設定任何 Secrets。

1. 到 GitHub 建立一個**公開** repo，名稱為 `social_sunny`。
2. 把這個資料夾的檔案全部上傳，**保持資料夾結構不變**：
   ```
   index.html
   fetch_and_update.py
   data/db.json
   .github/workflows/update.yml
   README.md
   ```
3. 進 repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`，存檔。
4. 進 **Actions** 頁籤。第一次進去 GitHub 會問要不要啟用 workflow，按下啟用。
5. 選左側「更新資料」這個 workflow，按 **Run workflow** 手動跑一次，把真實資料灌進去。

完成後的網址：

```
https://lindor8787-sun.github.io/social_sunny/
```

之後台北時間**每天 09:00 與 20:00** 會自動更新。公司、家裡、手機，任何裝置開同一個網址看到的都一樣。

> 如果 Actions 跑完卻沒有產生 commit，通常是因為抓回來的資料跟上次完全相同——這是正常的，腳本只在內容有變化時才 commit。

## 二、本機直接開 vs 部署後

| | 雙擊 index.html | 部署到 GitHub Pages |
|---|---|---|
| 能不能看 | 可以 | 可以 |
| 看到的資料 | 內建的種子資料（固定不變） | 每天自動更新的即時資料 |
| 原因 | 瀏覽器禁止 `file://` 讀取旁邊的 json | 正常 HTTP 讀取 |

程式會自動判斷，不需要你做任何切換。想快速確認畫面，本機開就夠了；要看真實資料就開網址。

每個來源互相隔離：其中一個掛掉不會影響其他來源，頁面會顯示上次成功抓到的內容，並在「資料來源與設定」標成紅點。

### 已知限制

- **Motive 對瀏覽器回傳的是 HTML 頁面而非 RSS。** 腳本用的 User-Agent 與請求標頭和瀏覽器不同，實測可以取得 feed，但若日後該站調整行為導致解析失敗，頁面會顯示「來源抓取失敗」而不會整個壞掉。
- **沒有「今天哪裡有折」。** 服裝折扣沒有任何公開統一資料源，硬寫只會給你過期或錯誤資訊。「生活情報」頁改放換季檔期的節奏整理與品牌查詢入口。
- **沒有法規動態自動更新。** 全國法規資料庫擋自動抓取、憲法法庭沒有 feed。立法院有「法律提案」API，但那追蹤的是提案進度，不等於法規異動，拿來當法規動態會誤導。因此法律區採「人工查證的靜態知識 + 官方查詢入口」。

## 四、法律知識區的性質

法律區的每一條都是在 **2026-11-18** 當天從全國法規資料庫與財政部公告逐條抄錄的，不是憑印象寫的。但請注意：

- **這不是法律意見。**
- 法規會修正、金額會逐年調整。遺產稅免稅額與扣除額幾乎每年都動，隔年請重新確認。
- **民法 §1223（特留分）在 115 年 8 月 17 日修正公布，自公布後六個月施行。** 查證當日法規資料庫同時掛著「部分條文尚未生效」的提示，顯示版本已不含「兄弟姊妹」。實際案件務必先確認適用哪個版本——頁面上也有同樣的警告。
- 要處理真實的繼承、簽約或權利主張，請找律師、地政士或會計師。

## 五、想改東西的話

**改更新時間**：編輯 `.github/workflows/update.yml` 的 cron。格式是 UTC，台北時間要減 8 小時。
現在是 `0 1,12 * * *`（台北 09:00、20:00）。改成每天只跑一次早上八點就是 `0 0 * * *`。

**加／換資料來源**：編輯 `fetch_and_update.py` 最上方的 `FEEDS` 清單，加一行就好：

```python
{"key": "自訂代號", "name": "顯示名稱", "source": "來源名", "url": "feed 網址"},
```

RSS 2.0 與 Atom 都支援，不用改解析程式。加完記得到 `index.html` 的 `PAGES` 與對應的 `RENDER.*` 把它放進想要的分頁。

**改菜價看的市場**：`fetch_and_update.py` 的 `VEG_MARKET_PREFIX`，預設 `"台北"`。想看台中就改成 `"台中"`。

**改每個來源保留幾則**：`PER_FEED_CAP`，預設 60，超過的會從最舊的開始淘汰。

## 六、隱私

這個站**不收集也不儲存任何個人資料**。

收藏、深淺色、閱讀紀錄只存在你當下那台電腦的瀏覽器 localStorage 裡，不會上傳、不會進 repo、換電腦不會跟著走。repo 裡的 `data/db.json` 只有公開新聞與公開行情資料。

因為沒有個人資料，所以 repo 設公開是安全的（GitHub Pages 免費方案也需要公開 repo）。

## 七、本機測試

```bash
cd social_sunny
python fetch_and_update.py      # 手動抓一次，更新 data/db.json
python -m http.server 8000      # 然後開 http://127.0.0.1:8000
```

排程只在 GitHub 上跑，本機執行腳本只會更新你本機的 `data/db.json`。
